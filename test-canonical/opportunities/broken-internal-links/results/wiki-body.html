Broken internal links detection — controlled head-to-head (deep dive)

To compare internal-link detection on a like-for-like basis, I reused the controlled AEM Edge Delivery test site quentin-eds-test.ca and added a one-isolated-defect-per-page matrix for broken internal links (the slug names the defect; content is a believable site). Because every defect is planted by design, the scenario column is the known ground truth; each tool is scored against it. Status-code targets (410 / 403 / 503, a 302 temporary redirect, a 301→404 broken redirect, and a 302 loop) are served by a Cloudflare worker so they resolve identically for both crawlers; structural link surfaces the CMS pipeline strips (form / image-map area / iframe) are injected into the rendered DOM, which ASO scrapes.

  • ASO = production spacecat-audit-worker src/internal-links (crawl path: scrape rendered DOM → extract links → HTTP HEAD/GET probe → classify status bucket). The net-new Mystique Preflight DOM checks (missing-href, insecure-link) are not credited to ASO.
  • SemRush = Enterprise Site Intelligence (JS-rendering ON) — combines its Internal Broken Links, Redirect Chains, Temporary / Broken Redirects, Orphaned Pages, Pages with Few Incoming Links, and Internal Nofollow issue reports.

Scope (two tiers). The head-to-head (Tier 1) scores internal-link health — a link that resolves to an error or redirect state, or carries a crawl-blocking nofollow attribute. Tier 2 (internal-linking structure: orphaned / few-inlinks) is reported separately: whole-site link-graph capability SemRush has that this ASO opportunity does not yet check.

Scorecard (Tier 1 — internal-link health)

Scoring rubric (equal weight, ground truth = planted defect): each scenario scores 2 = correct & specific, 1 = partial (flagged but mislabeled/generic), 0 = missed. Coverage = share scoring ≥1; Accuracy = points ÷ 24; Precision = correct-primary flags ÷ total flags emitted. Overall = harmonic mean of Accuracy and Precision (an F1-style blend: a tool can't win by flagging everything or almost nothing).

This evaluation scopes the auto-detect layer: how completely and how specifically each tool surfaces broken internal links. Specificity matters because a precise classification is actionable where a generic flag is not — ASO assigns a status bucket per broken link (not_found_404 / gone_410 / forbidden_or_blocked / server_error_5xx / soft_404 / redirect_chain_excessive), whereas SemRush reports a single coarse "Broken" bucket (it shows the status code but applies no differentiated handling).

Headline: ASO wins the core (86 vs 67). The two tie on the straightforward 4xx/5xx targets and the 302 redirect loop, but ASO uniquely catches the soft-404, the form-action link, the image-map area link, and the 301→404 broken redirect — each with the correct status bucket. The one core check SemRush wins is the internal nofollow link (#13), which ASO does not check today — an easy native gap to close (see Recommendations). SemRush is precise but has materially lower recall. Both miss the iframe embed (#10) and the single 302 temporary-redirect hop (#11) — both low-severity (see Notes). Recommendations

Guiding principle: a detection is only as valuable as it is fix-ready — specific and accurate enough to drive an auto-suggestion and an auto-fix. ASO's native checks are fix-ready by design (each broken link carries the status bucket, itemType and anchor text); SemRush's coarse "Broken" bucket is suggestion-grade until mapped to a fixable ASO defect type.

Recommended path

Option 3 now, Option 4 next. ASO already owns the broken-internal-links opportunity outright (86 vs 67) and is the only fix-ready detector. Take the easy native win first — add the internal-nofollow check (detect + strip) and, optionally, the two small link-surface gaps. Then scope structure auto-detect (orphaned / few-inlinks) as its own native internal-linking opportunity built from the crawl graph, with SemRush available as a parallel coverage-net while it is built. Options 1-alone (leaves Tier 2 uncovered) and 2 (can't feed the fix pipeline, lower core recall) are weaker for this goal.

Strategic notes

  • Detection granularity: ASO assigns a specific status bucket per broken link; SemRush reports a single coarse "Broken" bucket (it shows the code but applies no differentiated handling), so an imported finding must be re-derived before it can drive a fix.
  • SemRush is precise but noisy out of band: zero broken-link false positives, yet it flagged the Edge Delivery /nav and /footer includes as orphaned / few-inlinks — structural noise a native ASO check would avoid.
  • Migration: the broken-internal-links audit is being unified across ASO + Preflight under SITES-45047 (migration profile, SDL ADR Branch A); the Preflight↔audit output contract is SITES-43640. The net-new Mystique Preflight checks (missing-href, insecure-link) were excluded from ASO's score above.

Notes

  • JS-injected surfaces were detected: the form-action (#8) and image-map area (#9) links exist only in the rendered DOM (the CMS pipeline strips raw form/area tags), and ASO flagged both — confirming it scrapes the rendered DOM. SemRush (JS-rendering ON) still did not surface them.
  • Soft-404 (#3) = a target returning HTTP 200 whose body says the content no longer exists. ASO's soft_404 check caught it; SemRush, which keys off the status code, cannot.
  • #10 iframe → 404 — what it costs: the embedded content fails to load, so the user sees a blank or error frame where a widget/map/video should be, and the embed adds a dead request. It is a broken embedded resource rather than a click-through link, so severity is lower than a broken navigational link — which is why it sits below the nofollow win.
  • #11 temporary redirect (302 → 200) — what it costs: the link still works for the user, so there is no broken experience. The issue is SEO hygiene: a 302 signals "temporary," so search engines may not consolidate ranking signals onto the destination, and every hop adds latency and crawl cost. Best practice is to link directly to the final URL (or use 301 if the move is permanent). Low severity.
  • Image-map area (#9): ASO flagged the injected <area href> pointing at a 404 (the navigational defect); SemRush did not surface it.
